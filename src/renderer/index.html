Set up a view-only wallet

      
Uses the official Safex wallet tool, in view-only mode: it can see payments coming in but can never spend. You will paste your address and private view key once, into the wallet tool's own window, never into this app. Never use your seed or spend key.

      

        
        
        
      

      

      

    

    

      
Already use a different wallet? Skip the setup above. Run the official safex-wallet-rpc for it yourself (SOLO-SYNC Wallet uses 127.0.0.1:18083) and enter its address here (normally 127.0.0.1:18082; your node's 17402 is not it). Local addresses only; only incoming payments are read.
